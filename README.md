# DARKEST GRAND PRIX

*Ruin has come to our paddock.*

A browser prototype: Darkest Dungeon's gothic roguelike dread, except it's an F1 team.
Drive your cursed race car down a haunted highway in 3D, pick your route, and fight
2D turn-based battles against Backmarkers, the Stewards' Inquiry, the Weather, and
ultimately THE SAFETY CAR. Manage HP and TILT — at 100 tilt a crew member has a
radio meltdown.

## Run it

```sh
pnpm install
pnpm dev
```

Then open the URL Vite prints (usually http://localhost:5173).

## Build

```sh
pnpm build && pnpm preview
```

## The crew

- **The Relic** — won everything in 1997, will tell you about it
- **The Rookie** — sponsored by a drink that is legally a solvent
- **The Engineer** — wields a wrench named Gerald
- **The Strategist** — inventor of the rhombus strategy

Survive 6 legs. Reach the chequered flag. Or DNF trying.
